# Contributing

Thanks for your interest in NexaForge CMS.

1. Create a focused branch from the current main branch.
2. Keep controllers small and move reusable behavior into services.
3. Preserve English/Persian and LTR/RTL behavior for UI changes.
4. Validate all uploaded files and never introduce arbitrary server-side package execution.
5. Add or update tests for behavioral changes when a test project is available.
6. Never commit credentials, local databases, generated uploads or IDE-specific files.
7. Use clear commits that explain the engineering intent, not only the changed file.
