## Description
AI-powered, extensible enterprise CMS built with ASP.NET Core MVC — bilingual RTL/LTR authoring, modular plugins & themes, editorial workflows, SEO, analytics, security and production-engineering tooling.

NexaForge CMS is designed as a portfolio-scale product rather than a collection of isolated CRUD demos. Reviewers can inspect content workflows, authentication and authorization, extension-package safety, AI service boundaries, database upgrade compatibility, diagnostics, portable backup design and bilingual responsive UX in one coherent ASP.NET Core MVC solution.
